# V2-A1.20D / A1.21P 结果交接

日期：2026-07-18

## 核心结论

A1.20C 的 N5 失败根因已被修复：旧 factorized compiler 只让 entity 边界约束 operation，没有把 refined operation start 反馈给最终 entity decode。改为粗 operation → entity → refined operation → final entity 的三遍双向 section 推断后，原 checkpoint 无需重训即可通过 canonical 完整 split matrix、hidden causal audit 和 routing surface OOD。

这说明 full-text hybrid 的核心机制已经从失败状态恢复为强候选；但 A1.21P 正式合同不通过。当前只有五条在线 smoke、一个 COPY/SWAP 表面改写族、三个共享初始化的 schedule continuation，且没有训练/teacher 公平预算和完整成本审计。因此 A1.22A 按 Gate 停止，未运行。
