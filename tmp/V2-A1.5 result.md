# V2-A1.5 结果总结

日期：2026-07-13

## 最终结论

V2-A1.5 **未通过 Gate**，但完成了预期的分层诊断。

- P0 结构化输入正控制可以稳定过拟合并在 ordinary test 上完成逐步状态更新，说明 shared recurrent transition、mask、state CE 和 answer CE 本身可工作。
- P0 在未见过的 `swap->copy` composition 上 final `0.2734`、state full exact `0`，说明 operation-conditioning 的组合泛化尚未成立。
- P0 在 5–6 步 length-heldout 上 final `1.0`，但 state full exact 只有 `0.2266`，答案正确不能替代状态轨迹正确。
- P1 已真实编码 Qwen3.5-2B hidden；4096-cache warm-up、联合训练、validation 早停记录和 best checkpoint 重载均完成，ordinary validation final/state 均为 `1.0/1.0`。这只证明 surrogate interface 在 ordinary split 可拟合，不等于 composition/length 泛化或原始文本能力保真。
- P2 在 P1 正式 Gate 后完成 K=8 learned-slot 训练。ordinary test final/state 为 `1.0/1.0`，composition 为 `0.2773/0`，length 为 `1.0/0.6484`；learned workspace 在普通分布可工作，但 A1.5 composition Gate 仍失败。
- Qwen3.5-0.8B matched visible baseline 已完成 test zero-shot 128 条 no-cap formal：parse `0.1797`、final `0.0625`、state full `0.0234`；118 条语义终止、10 条透明 wall-time timeout。这个结果是基线证据，不是 latent 质量结论。
- composition-heldout zero-shot 128 条也已完成：parse/final/state full `0.4063/0.3828/0.3750`，全部语义终止；final 仍低于 prefix-2 `0.4727`。
- length-heldout zero-shot 128 条也已完成：parse/final/state full `0.0625/0/0`，全部语义终止；生成 token `15,643`，总耗时约 `1333.4s`。
- 2-shot test/composition 各128条已完成：parse/final/state full 分别为 `0.9766/0.1328/0.0156`、`0.9219/0.1953/0`；分别有3/7条 timeout。2-shot 只改善格式解析，没有恢复状态或组合泛化。
- 2-shot length-heldout 128 条已完成：parse/final/state full `0.7656/0.0938/0`，29 条 timeout；因此 2-shot 也没有恢复长度状态轨迹。
- A3、A4、V2-B 均未启动。

本轮不能得出“连续 latent 不可能”，也不能得出“latent workspace 已建立”。更准确的结论是：

> P0 排除了“recurrent core 完全不能执行”的解释；P1 ordinary hidden→latent 接口已能建立，但当前主要失败位于未见 operation 组合的递归泛化、composition 上的样本身份依赖和逐步 state 可靠性。可见文本基线还受无终态 completion 的资源边界影响。

## 二、遇到的问题

### 1. 不是 P0 transition 实现完全错误

P0 可以 overfit，也能在普通 train/validation/test 上达到 final/state full exact1.0。错误归因“shared recurrent architecture 完全不成立”不成立。

### 2. Operation-conditioning 不能组合未见 bigram

普通训练显式排除 swap->copy，composition 只改变这个相邻 family 组合而保持长度。P0 单步与已见序列执行正确，但 composition final/state 为0.2734/0。当前 operation embedding + cross-attention 没有形成可检查的代数状态更新，容易学成“见过序列的映射”。

### 3. Final answer 与 state trajectory 脱钩

P0 的 length final1.0，但 state full exact0.2266；P2 正式训练把 length state full 提到0.6484，却仍未达到完整轨迹 Gate。受限模板可能让答案头先学到结果映射，逐步 state probe 仍不正确。后续必须把逐步 state exact 放在 final answer 同等门禁位置。

### 4. P1 的 cache 管线成功，small 训练失败但 formal ordinary 已修复

真实 Qwen hidden cache 的版本、分片、FP16、span mask 和 no-truncation 已验证。small 300-step probe 的 validation final0.2188、state0.4491 暴露了训练预算/两阶段目标不足；不能把这一次 underfit 直接归因于 hidden→latent 接口失败。4096-cache warm-up + joint training 后 ordinary validation/test final/state 均为1.0，但 composition final/state 只有0.3242/0.3290，说明接口可训练不等于未见组合的信息保真。

P2 进一步说明：即便 frozen hidden 到 learned K=8 workspace 在 ordinary split 能拟合，composition final0.2773、state full0，且 same-answer shuffle changed prediction rate0.8125；接口可训练不等于组合泛化或样本身份不变性。

### 5. 因果干预不是只看 prediction change

replace/delete 会改变部分预测，但修改后的轨迹 oracle accuracy 仍很低。P2 的 transition-delta shuffle/截短会使 state full 降到0，而 composition 的 same-answer shuffle 却让预测大幅改变；这同时证明了“模型确实读了递归轨迹”和“模型还依赖输入身份”两件事。只报告 changed prediction rate 会夸大因果证据；必须同时报告 counterfactual state/final exact、same-answer stability 和 trajectory truncation。

### 6. 数据生成曾有两个合同错误，已修复

- 初版随机长度让 train 主要是1步，validation 长度分布偏移；改为每个长度显式配额；
- 初版 length split 混入 composition tag；加入首 COPY 后 SWAP 的必要性模板后，length composition rate降为0。

### 7. 无输出上限会暴露模型未给终态的问题

用户要求不限制输出长度后，不能用隐藏 `max_new_tokens` 掩盖 Qwen3.5-0.8B 的未终止 completion。128 条 test zero-shot formal 的 parse/final/state full 只有 `0.1797/0.0625/0.0234`，10 条触发 safety wall timeout，最长生成 `1088` tokens，峰值显存约 `1.74GB`。当前实现已经把完整状态轨迹作为合法语义终态，并保留未解析 completion；这正是 visible baseline 的终止/资源边界，不是 latent 质量结论。

## 四、结论与下一门禁

本轮应停在 A1.5，不启动 A3/A4/V2-B。下一轮优先级：

1. 为 P0 operation-conditioning 增加可检查的 relation binding/algebraic state update，重新验证 swap->copy；
2. 保留 P1 warm-up→joint、best reload 和 explicit span contract，增加多 seed 与 composition/length 信息保真验证；
3. 优先修正 P0/P2 的 operation relation binding 与样本身份依赖，再比较 K=1/4/8/16；
4. 继续使用 no-op necessity、counterfactual state exact、trajectory truncation、same-answer shuffle 和 disable-delta；
5. 先完成 matched visible text baseline 的可审计终止矩阵，再讨论 latent 的质量—成本 Pareto；
6. A1.5 未通过前不启动 A3 audit、A4 formal 或 V2-B。
