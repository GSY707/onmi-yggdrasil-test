# V2-A1.12–A1.17 根因实验结果

日期：2026-07-17

## 核心结论

当前 A1.10/A1.11 Reasoner 失败不是纯 Boundary × Reasoner 组合故障，也不能主要归因于 anonymous binding、operation cursor、early-stop、坏初始化或 query-coupled 后的重复 answer CE。A1.12–A1.17 把剩余故障定位到两个层次：

1. state recurrence 要稳定学会任务，需要 relation-addressed transition 与 soft latent closure 联合存在；generic recurrent Transformer 即使获得 entity-addressable slots 和 aligned cursor，仍不能在正式分布上形成算法。
2. 在这个已修复的 state core 上，当前训练又依赖独立 `workspace mean → answer head` 的 answer CE 作为全局优化脚手架。删掉该独立目标后，query-coupled + answer CE 和 query-coupled + no answer CE 在完全相同的三个成功共享初始化上都变为 state `0/3`。但保留独立 answer head 时 full Gate 只有 `1/3`，它会与正确 state 脱钩，不能作为可靠的最终输出。

因此根因不是一个缺失模块，而是“结构归纳偏置不足 + 训练目标悖论”：当前系统必须借助一个不满足最终因果输出合同的答案旁路才能进入 state 学习盆地。`root_cause_localized=true` 只表示当前 exact-symbolic 三寄存器诊断合同内的失败源已经定位；`architecture_validated=false`。

## 严格解释边界

已经确认的是当前优化系统的必要依赖，不是“独立答案旁路是目标架构正确组件”。A1.13 的 state `3/3` 与 full `1/3` 同时说明：这个目标能帮助 transition 学习，却不能保证答案忠实读取 state。

当前实验尚未拆开独立辅助目标的三个成分：全局 workspace pooling 的梯度几何、query-answer 标签、额外 auxiliary head 参数。也没有覆盖 learned full-text Boundary、匿名开放世界 workspace、Qwen 端到端、matched text-CoT Pareto、A3/A4 或 V2-B。因此不能从本结果推出完整 V2 架构成立。

## 下一步

下一阶段应直接重设训练合同，不再做 loss weight 或学习率 sweep。建议 A1.18 使用 query-coupled state 作为唯一推理答案，同时把独立 pooled head 降级为仅训练期 auxiliary，并做两个预注册对照：

1. `QAUX`：pooled workspace → queried answer CE，只在训练中使用，精确复现 A1.13 的全局辅助梯度；正式答案仍从 queried final state 读取。
2. `SAUX`：pooled workspace → 三个寄存器的完整 final-state CE，只在训练中使用，测试能否用非答案旁路的全局 state 辅助替代 QAUX。

先在 A1.17 的三个 paired seed 上运行；只有某臂 state/full `3/3` 且因果干预 `3/3`，才进入全新 model seed 稳定性复验。QAUX 通过、SAUX 失败表示 answer-label-specific shortcut 仍是关键；SAUX 通过才说明可以形成不依赖答案旁路的训练目标；两者都失败则应停止当前 core，而不是继续小修。
