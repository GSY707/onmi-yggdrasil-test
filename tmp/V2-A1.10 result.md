# V2-A1.10 实验结果

日期：2026-07-16

状态：完成；overfit32 passed，formal `0/3`，总 Gate failed

## 核心判断

A1.10 按要求在同一轮删除 oracle span mask 和显式三寄存器 scaffold，真实实现了完整 frozen Qwen token hidden、匿名 `K=8` workspace 与两层共享通用 recurrent Transformer。实现可以 overfit 32 条样本，但三个独立 data/model seed 的正式 trajectory 几乎为零；final state 和 final answer 只达到约 `0.4–0.6`。因此当前联合架构与训练合同没有成立。

这不是对所有匿名 latent reasoning 的否定。A1.10 同时改变了 full-text boundary、workspace 和 reasoner，失败不能单独归因到其中某一项。

## 方法合同与修正

- Qwen3.5-2B revision `15852e8c16360a2fea060d615a32b45270f8a8fc` 完全冻结；
- cache 只保存完整 last hidden 和 attention mask，无 offset、span、operation mask、typed role tensor 或 input ids；
- `K=8`、`D=256`、两层共享 pre-norm self-attention/cross-attention/Dense FFN；
- 无 register slot/key、role adapter、COPY/SWAP transition、step embedding、teacher state 或答案直读 source；
- T1–16 统一运行 16 步，前 `L` 步监督真实轨迹，之后监督最终状态保持；T20/T24/T32 运行对应步数；
- 唯一 loss 为逐步 `3×10` state CE 与 final answer CE，权重 `1.0/1.0`。

第一次 run 1 训练后、正式 full evaluation 前，发现旧 validation 曾按程序长度运行 T1/T8，而训练统一运行 T16，造成 final answer 预算不一致。错误预算产生的 overfit/formal 和 run-1/formal checkpoint 已删除。修正后 overfit 与三个 formal run 全部从头训练；本结果只引用修正版产物。

## 正式结果

overfit32 best step `800`，step `1000` 稳定停止；T1–16 trajectory、final state、answer 全 `1.0`。

| --- | --- | --- | --- | --- | --- |
| 1 | `2600/4000` | `0.003906/0.496094/0.593750` | `0/0.429688/0.523438` | `0/0.417969/0.562500` | `0/0.453125/0.539062` |
| 2 | `3400/4000` | `0/0.437500/0.539062` | `0/0.468750/0.574219` | `0/0.484375/0.609375` | `0/0.468750/0.574219` |
| 3 | `3600/4000` | `0/0.484375/0.597656` | `0/0.488281/0.597656` | `0/0.515625/0.613281` | `0/0.496094/0.605469` |

short aggregate trajectory 为 `0.002604/0.003906/0.002604`，causal-core trajectory 三组均为 `0`。三个 run 的正式 Gate 全部失败，architecture integrity 是唯一通过的能力外 Gate。

训练集每长度各 32 条的只读诊断 trajectory aggregate 也只有 `0.005859/0.001953/0`；这不是仅在 relation 或 OOD 上失败，而是当前模型没有在正式训练分布上学成逐步状态更新。loss 与 token-level state/answer 仍在下降，说明训练链有梯度，但 marginal learning 没转化为 exact trajectory。

## 干预停止点

预注册规定普通 formal 通过后才允许生成反事实 Qwen cache 和运行 hidden interventions。三组普通 formal 都失败，因此 prefix、replacement、deletion、operation shuffle、query swap、same-answer/different-trajectory、no-source、independent-source shuffle、disable-recurrence 和 slot permutation 全部未运行。

“未运行”不是“干预失败”。总评估的 intervention Gate 为 false，是因为所需证据不存在，而不是执行后得到负指标。

## 成本

- 三组 full-token cache：`68,352` examples、`9,046,290` source tokens、`38,358,822,720` bytes；
- Qwen 净编码：`4,767.62` 秒，不含模型/tokenizer 首次加载；
- Qwen 编码峰值 allocated：约 `5.18` GB；
- 三组训练：`384,000` examples、`6,144,000` recurrent transitions、`3,256.60` 秒；
- trainable reasoner：`3,434,536` 参数；
- cached batch-32 train：`0.18009` 秒/step；
- cached T16 inference：`0.03156` 秒/batch；T24：`0.07378` 秒/batch。

这些成本不含在线 Qwen 编码，也没有 matched text-CoT 对照，不是 Pareto 证据。

## 完成与未完成

已完成：架构预注册、full-token Qwen cache、三组 cache audit、修正版 overfit32、三组独立正式训练与全 split formal、跨 run fingerprint 检查、CUDA 成本 benchmark、机器总评估、测试与文档同步。

未完成且按 Gate 停止：全部 hidden interventions、matched text-CoT、A3 audit、A4 architecture-formal、V2-B。

## 下一步

不继续对当前联合配置做 K/T/层数/训练步数 sweep。下一轮拆成两个对称诊断：

1. `A1.11-Boundary`：full-token Qwen → learned typed role reader → frozen A1.8 core；
2. `A1.11-Reasoner`：oracle typed role sequence → anonymous K-slot generic reasoner。

只有这两个实验才能区分 full-text role discovery 与匿名 recurrent state binding。若二者都通过而联合失败，再归因接口组合/联合优化。
