# V2-A1.13F：Fixed-budget Early-stop 方法审计

日期：2026-07-16

状态：已完成；fixed budget 未消除单因素 seed 不稳定

## 1. 为什么必须审计实验方法

A1.13-STRUCTURED-CE run 1 在 step 1400 前 trajectory 仍接近零，step 1600 后出现明显算法相变，step 2400 后 state Gate 达标。run 2 在 step 1600 前尚未出现相变，并被预注册的 6 次 validation patience 停止。此时把 run 2 直接解释为结构失败，会把“相变前 early-stop 误杀”混入架构归因。

A1.13F 不修改模型、数据、loss、batch、学习率或最大预算，只审计 early-stop。它不是原 formal 的事后续训：所有受审计 run 都 fresh 初始化并从 step 1 重跑；原 A1.13 ordinary formal 结果保持不变。

## 2. 配对合同

使用 A1.13 相同的 data/model seed `20260721/20261321`、`20260722/20261322`、`20260723/20261323`，比较：

1. GENERIC-CE：A1.12-BOTH，固定跑满 4000 steps；
2. GENERIC-CLOSURE：A1.13 同名臂，固定跑满 4000 steps；
3. STRUCTURED-CE：A1.13 同名臂，固定跑满 4000 steps。

实现上把 `early_stop_patience` 设为大于全部 validation 次数的 `100`；validation/checkpoint 每 200 steps、best checkpoint scoring 与 formal Gate 均不变。若某臂连续两次满足全部 readiness Gate，允许按原成功停止规则提前结束，因为这不是失败误杀。

run 1 STRUCTURED-CE 已实际跑满 4000 steps，可作为相同合同证据复用；其他未跑满的 ordinary run 不得冒充 fixed-budget run。

## 3. 判定

- fixed STRUCTURED-CE state Gate `3/3`，fixed GENERIC-CE state Gate `0/3`：generic transition identity 是稳定的逐步状态主根因；ordinary STRUCTURED-CE seed 不稳定主要来自 early-stop 方法。
- fixed GENERIC-CLOSURE state Gate `3/3`：closure 是保留 generic transition 的替代充分修复；若 STRUCTURED-CE 也通过，二者均非唯一修复。
- fixed STRUCTURED-CE 仍非 `3/3`：relation-addressed transition 只有 seed-dependent 收益，不能写成稳定根因。
- fixed GENERIC-CE 出现通过：A1.12 的 `0/3` 受 early-stop 混淆，必须撤回“binding/cursor 不足”的稳定口径。

state Gate 与完整 Gate分开报告。只有 trajectory、final state、state-token、relation/OOD/causal 全部通过才算 state Gate；联合臂的 answer-only failure 交给 A1.15，不得反向否定 state transition 结果。

## 4. 审计结果

九个配对 run 均实际跑满 4000 steps；成功停止规则没有提前截断任何受审计 run。state Gate 结果为：

| arm | fixed-budget state Gate | 结论 |
| --- | ---: | --- |
| GENERIC-CE | `0/3` | A1.12-BOTH 的失败未被预算救回 |
| GENERIC-CLOSURE | `0/3` | closure 单因素未被预算救回 |
| STRUCTURED-CE | `1/3` | 与 ordinary 结果一致，仍为 seed 不稳定 |

GENERIC-CLOSURE 的第三 ordinary run 本来就跑满 4000 步，因此与两个 fresh fixed-budget run 共同构成三 seed 审计；STRUCTURED-CE run 1 同理。其余 run 使用 `early_stop_patience=100` fresh 重跑。所有 generic 单因素臂的正式 trajectory 仍接近零。

机器分类为 `fixed_budget_seed_instability_persists`。因此 early-stop 不是 A1.12/A1.13 单因素失败的主根因；relation-addressed transition 的 `1/3` 收益是真实但不稳定，soft closure 必须与其联合才把 state 提升到 `3/3`。
