# Project-Yggdrasil V2-A1.8：随机深度长程递归验证

后续状态：A1.9 frozen-Qwen oracle-role boundary 已于 2026-07-15 以 `3/3` 通过；联合删除 oracle spans、显式寄存器 scaffold 并切换通用 reasoner 的 A1.10 于 2026-07-16 以 `0/3` 失败。本文的概率与“下一步”保留为 A1.8 完成时快照，当前路线以 `docs/next-stage-test-plan.md` 和 `docs/v2-a1.10-anonymous-workspace.md` 为准。

日期：2026-07-15

## 目标与唯一变量

A1.8 只回答一个问题：A1.7 在 T12/T16 的漂移主要来自训练深度只覆盖 T1–4，还是来自 shared continuous transition 的内在递归不稳定。

目标架构不变，继续使用 A1.7 的 content-only state slots、独立 register address keys、唯一 shared transition、共享 state/answer head 和权重 `1.0` 的 stop-gradient prototype closure。A1.8 不新增 projector、residual scaling、hard re-embed、oracle reset、Qwen hidden、匿名 slots、audit、MoE 或多模态。唯一设计变化是把训练 regimen 切换为 T1–16 的随机深度；这也必然改变每个 sampled example 的平均 transition exposure，因此不是严格 compute-matched 的单变量因果实验。

每个训练 batch 在 T1–16 上严格均衡采样，不使用从短到长的单向 curriculum。best checkpoint 按 validation 的最差长度 trajectory 优先选择，避免 aggregate 掩盖某个 horizon 的失败。

## 训练合同

每个 run 都从 fresh initialization 开始，配置固定为：latent width `256`、FFN width `512`、batch `128`、AdamW、learning rate `3e-4`、最多 `8000` steps、每 `200` steps validation、patience `15`、gradient clipping `1.0`、closure weight `1.0`。训练时每个 batch 对 16 个长度等量采样。

在正式训练前，使用每个长度 2 条、共 32 条样本运行 length-balanced overfit sanity。overfit 需要所有长度 trajectory、source pointer、target pointer 达到 `0.999`，并保持 answer/state identity。

## 正式 Gate

每个 run 独立判定：

1. short_regression 的 T1–6 每个长度 trajectory full `>=0.95`；
2. supported_in_range 的 T8/T12/T16 每个长度 `>=0.95`；
3. relation_in_range 的 T8/T12/T16 每个长度 `>=0.95`；
4. supported_ood 的 T20/T24 每个长度 `>=0.90`；
5. relation_ood 的 T20/T24 每个长度 `>=0.90`；
6. causal_core free trajectory `>=0.95`；
7. 所有正式 split 的 source/target pointer aggregate `>=0.995`；
8. answer/state logits identity 和 prototype non-collapse 全部通过。

T32 必须完整报告，但不进入 trajectory 硬门槛。这个边界在正式训练前冻结，不能根据结果移动。

formal Gate 通过后才运行 causal intervention：prefix `>=0.99`，replacement/deletion/shuffled trajectory `>=0.95`。A1.8 总 Gate 要求三个数据/model seed 的 data audit、formal 与 causal 全部通过，并且跨 run fingerprint overlap 为零。

## 稳定性诊断

每个 formal split 记录逐步 state full/state token、latent norm、正确 prototype cosine、正确与最近错误 prototype margin、首次错误位置。另对 initial slots 注入 RMS `1e-3` 的连续扰动，报告每一步扰动放大率的 mean、P95 和 max。

这些指标只用于区分漂移来源，不替代 trajectory Gate。若随机深度训练仍不能稳定通过 T16，下一阶段才允许根据诊断在 continuous projector、residual scaling 或局部稳定性约束中只选择一个结构变量；禁止同时堆叠多个补丁。

## 判定边界

若三个 run 全部通过，只能声称：在当前结构化 COPY/SWAP core 上，A1.7 的 T16 失败主要是训练 horizon mismatch，随机深度训练可把稳定递归推进到 T24 Gate。仍不能外推到 Qwen hidden、匿名 workspace、自然语言、matched text-CoT Pareto 或完整 V2。

若任一 run 失败，A1.8 总 Gate 失败，但仍完成三个 run 以估计稳定性，不因单个 seed 失败而只保留有利运行。失败后先读稳定性诊断，再决定是否允许一个连续稳定化结构变体。

## 成本与规模

核心共有 `794,892` 个参数，全部 active/trainable，没有冻结参数和 KV cache。三个正式运行共处理 `204,800` 个 sampled examples、`1,740,800` 次 latent transitions，实测训练时间合计 `610.5` 秒；粗略 parameter-activation FLOPs proxy 为 `8.30e12`，不是 profiler 实测 FLOPs。

RTX 4070 Laptop GPU、batch `128`、3 warmup + 10 timed repeats 的独立 benchmark：

| 模式 | 延迟 | peak allocated |
| --- | ---: | ---: |
| length-balanced training step，1088 transitions/batch | 80.20 ms | 105.37 MiB |
| inference T8 | 5.15 ms/batch | 28.97 MiB |
| inference T16 | 10.01 ms/batch | 45.25 MiB |
| inference T24 | 31.07 ms/batch | 61.53 MiB |
| inference T32 | 41.08 ms/batch | 77.82 MiB |

这些数字只描述当前 structured core，不可与 Qwen text-CoT 直接比较，也不构成 V2-A Pareto。

## Gate 判定与归因修正

**A1.8 data、overfit32、三个独立 data/model seed 的 formal、T20/T24 OOD、causal intervention、cross-run overlap 和成本 artifact 全部通过，总 Gate 为 3/3 passed。**

A1.7 的 T16 supported mean 为 `0.910156`，A1.8 提升到 `0.998698`；relation mean 从 `0.928385` 提升到 `1.0`。核心结构、容量和 closure 没有变化，训练 regimen 则同时改变了 horizon coverage、均衡采样和相应的 transition exposure。现有证据足以否定“这个 shared transition 在 T16 必然内在发散”，并强烈支持 A1.7 存在训练 horizon mismatch；但本轮没有 compute-matched 地拆分长度覆盖与 transition 预算各自的贡献。

这个归因仍受限于强结构化 value prototype、COPY/SWAP 状态机和最多 T32。不能声称自然语言 latent、匿名 workspace 或无限深递归已经解决。
