# V2-A1.11：Boundary × Reasoner 正交故障定位

日期：2026-07-16

状态：已完成；Boundary 严格 overfit Gate failed，Reasoner formal `0/3`，A1.10 纯组合故障解释被否定

## 1. 核心问题

A1.9 在 oracle role spans + structured core 条件下 `3/3` 通过；A1.10 在 learned full text + anonymous generic reasoner 条件下 `0/3` 失败。A1.10 同时改变 boundary、workspace 和 reasoner，不能判断失败来自单个组件还是组件组合。

A1.11 补齐另外两个格子：

| 输入边界 | structured A1.8 core | anonymous generic reasoner |
| --- | --- | --- |
| oracle typed roles | A1.9：`3/3` passed | A1.11-Reasoner：本轮测试 |
| learned full text | A1.11-Boundary：本轮测试 | A1.10：`0/3` failed |

两臂独立训练、独立判定，不用一臂结果调整另一臂合同。

## 2. A1.11-Boundary 合同

唯一被删除的能力 scaffold 是 oracle character/token spans。保留 A1.9 已验证的三个 A1.8 core、operation count/mask、typed output roles、逐步 core loss、mapping CE、prototype regression、训练长度和 formal Gate。

输入使用 A1.10 已审计的完整 frozen-Qwen last hidden + attention mask cache，不读取 offset、span、input IDs、role pooled hidden 或答案。learned typed reader 使用三个 initial-register queries、一个 query-register query，以及共享 family/source/target role queries；operation step 只加入固定 sinusoidal position，不为 T17–32 建立未训练的独立参数。两层通用 query self-attention/full-source cross-attention/Dense FFN 直接输出不受额外 LayerNorm 约束的 typed latent，使其能回归 frozen core 的原始 prototype 几何，再驱动完全冻结的对应 A1.8 core。

operation mask 在本臂中继续保留，因为本臂只隔离 span discovery；因此通过不等于自主发现程序长度，也不等于匿名 reasoning 成立。

三组正式配置：

| run | data seed | frozen core seed | reader seed |
| --- | ---: | ---: | ---: |
| 1 | `20260721` | `20260821` | `20261121` |
| 2 | `20260722` | `20260822` | `20261122` |
| 3 | `20260723` | `20260823` | `20261123` |

先做 T1–16 length-balanced overfit32。所有长度 trajectory、mapping、source/target pointer 与 answer 必须为 `1.0`，core hash 必须不变。正式训练 batch `32`、最多 `5000` steps、每 `200` steps validation；checkpoint 按最差长度 trajectory、mapping 和 pointer 选择。

正式 Gate 与 A1.9 相同：short/T8/T12/T16 每长度 trajectory 不低于 `0.95`，relation 同阈值；T20/T24 不低于 `0.90`；causal-free trajectory 不低于 `0.95`；所有 split mapping/pointer 不低于 `0.995`；answer/state identity、prototype non-collapse、reader/core integrity 和 core hash 必须通过。三个 seed 必须 `3/3`。

## 3. A1.11-Reasoner 合同

本臂直接从不可变 A1.8 record 构造精确 symbolic typed role sequence，只测试匿名 workspace／通用 recurrent reasoner。Qwen、role-pooled cache、A1.9 adapters 与 structured A1.8 core 均不加载到可执行模型中。这样避免把连续 boundary latent 的几何误差带入 Reasoner 臂，保证两臂真正正交。

输入语义由固定 one-hot 构成：10 个 value 类、2 个 operation family 和 3 个 register identity；另显式标注 start-register 0/1/2、query、family、source、target 的 role type，并加入固定 sinusoidal operation-step features。禁止使用会让 T17–32 对应 source-projection 列在训练中永远无梯度的 step one-hot。reasoner 与 A1.10 保持 `K=8`、`D=256`、两层跨 step 共享的通用 self-attention/full-source cross-attention/Dense FFN；没有 register slots/keys、COPY/SWAP transition、hard re-embedding、teacher state、source-direct answer 或 step-specific recurrent 参数。

训练与 A1.10 相同：T1–16 均统一运行 16 recurrent steps，短程序结束后监督 final-state persistence；state CE 与 answer CE 权重均为 `1.0`，batch `32`、最多 `4000` steps。reasoner seed 复用 A1.10 的 `20261021/22/23`，data seed 按 run 对齐。

overfit32 必须在 T1–16 trajectory/final/answer 全为 `1.0`。正式 Gate 与 A1.10 相同：short 和 T8/T12/T16 每长度 trajectory/final/answer 不低于 `0.95`，T20/T24 不低于 `0.90`，causal-free aggregate 不低于 `0.95`，全部正式 split state-token 不低于 `0.995`，architecture integrity 与 data-manifest hash 必须通过。三个 seed 必须 `3/3`；T32 只诊断。

执行前曾短暂实现过“frozen A1.9 adapters 输出连续 latent → anonymous reasoner”的版本。该版本仍混入 boundary interface，不能回答本臂问题；其 checkpoint 和结果已删除，不进入 A1.11 证据。当前 exact-symbolic 合同是在 fresh 主实验前完成的方法纠正。

## 4. 干预与停止规则

每一臂先写普通 formal，再决定是否运行该臂干预。formal 失败的 run 不生成或运行干预，其他 run 仍继续，以识别 seed 稳定性。

Boundary 通过后必须对重新渲染并重新编码的 prefix/replacement/deletion/operation-shuffle/query-swap full text 做新 oracle 跟随，并测试 same-answer、no-source 与 source shuffle。Reasoner 通过后必须在 exact-symbolic records 上测试 prefix/replacement/deletion/shuffle/query swap、same-answer、disable recurrence 与 slot permutation。

未运行的干预不得写成执行失败。任何一臂 overfit32 失败时，该臂停止正式训练，但另一臂照常执行。

## 5. 归因规则

只按三 seed formal 结果作主归因，干预决定证据强度：

- Boundary `3/3`、Reasoner `0/3`：主故障在匿名 binding/通用 transition；
- Boundary `0/3`、Reasoner `3/3`：主故障在 full-text role discovery；
- 两臂都 `3/3`、A1.10 仍 `0/3`：支持接口组合或联合优化故障；
- 两臂都 `0/3`：两项独立替换都不足，不能归为纯组合故障；
- 任一臂只有 `1/3` 或 `2/3`：判为 seed 不稳定，不能作唯一原因结论。

本轮不通过增加 K/T/层数、解冻 Qwen、答案旁路、teacher forcing、oracle reset 或 loss sweep 救援失败配置。

## 6. 执行记录

Boundary fresh overfit32 在无输出 LayerNorm 的修正合同下运行到 5000 steps，所有长度的 trajectory、final state、answer 与 typed mapping 均为 `1.0`，但 source/target pointer 最低均为 `0.9642857143`，未达到严格 `1.0`；因此该臂 overfit Gate 失败并按合同停止 formal。只读 hard re-embedding 诊断把 reader mapping argmax 映射回 frozen core prototypes 后，全部 trajectory、answer 与 pointer 恢复为 `1.0`。这不是正式架构救援，只说明失败位于 learned continuous latent 与 frozen core 地址几何的接口，而不是 full-text 角色分类完全失败。

Reasoner exact-symbolic fresh overfit32 在 best step 800 达到 T1–16 trajectory/final/answer 全 `1.0`，step 1000 满足连续两次严格 Gate 后停止。该结果只证明匿名 reasoner 有小样本拟合容量。

三组正式训练分别在 step `3400/2800/2600` 停止，best step 为 `2200/1600/1400`，formal Gate 稳定 `0/3`。三组 short trajectory 为 `0.001302–0.002604`，in-range 为 `0–0.001302`，relation in-range 为 `0–0.002604`，T20/T24 supported 为 `0.001302–0.003906`，relation OOD 全为 `0`，causal 为 `0–0.001953`。final state 约 `0.03–0.23`，answer 约 `0.30–0.38`；所有 split 的最低 state-token 为 `0.3163–0.3387`。

best checkpoint 在训练集均衡子集上的 fit diagnostic 也只有 trajectory `0–0.003906`、final state `0.1523–0.1641`、answer `0.3711–0.3809`。因此失败不只是 heldout composition/length 泛化，而是当前大分布训练没有形成逐步算法；overfit32 证明的是有限记忆容量。

所有 run 的 architecture integrity 与 data-manifest hash 均通过。ordinary formal 全失败，所以 causal intervention 均按预注册未运行。

## 7. 最终归因

2×2 最终矩阵为：A1.9 oracle typed roles + structured core `3/3`；A1.11 Boundary 在严格内部 pointer overfit Gate 失败并停止；A1.11 exact-symbolic roles + anonymous reasoner formal `0/3`；A1.10 learned full text + anonymous reasoner `0/3`。

exact symbolic 输入下 Reasoner 臂仍稳定失败，已经足以否定“两个组件单独都成立、只有组合后才失败”的解释。主要独立失败源位于匿名 workspace／generic recurrent transition／当前 readout objective 这一整臂。Boundary 另有连续 latent 与 frozen core 地址几何不精确吻合的严格接口缺陷，但其 task-level formal generalization 因 overfit stop rule 未测试。

当前实验没有把 anonymous slot binding 与 generic transition 分开，也没有证明通用 Transformer 数学上不可能成立。下一阶段只应恢复一个最小 entity-addressable state scaffold，同时保留 exact symbolic roles 和 generic learned recurrence；不得回到 A1.10 的 K/T/层数或 loss-weight sweep。详细结果见 `tmp/V2-A1.11 result.md` 和 `artifacts/v2-a/a1_11/assessment-summary.json`。
