# V2-A1.15：Closed + Query-coupled 最小核心闭环

日期：2026-07-16

状态：已完成；触发条件成立，但 formal state/full Gate 均为 `0/3`，阶段失败

## 1. 目的

A1.13 的 validation 已显示：relation-addressed transition 与 soft prototype closure 联合后，多个 seed 的逐步 state 很快达到 Gate，而独立 `workspace mean → answer head` 明显落后。A1.15 只验证最后一个候选：答案是否必须与已学到的可审计 state 使用同一 readout，而不能保留独立旁路。

若 A1.13 联合臂任一 seed 的 trajectory/final/state-token、relation/OOD/causal state Gate 失败，A1.15 不启动；不得用 answer coupling 掩盖 state 失败。

## 2. 唯一变化

共同合同完整保留 A1.13-STRUCTURED-CLOSURE：exact symbolic entity/cursor、relation-addressed shared transition、soft stop-gradient prototype closure、state CE、相同 K/D、数据与预算。

唯一变化是删除独立 pooled answer head。answer logits 直接取最后 recurrent step 中 `query_register` 所指 entity slot 的共享 state-head logits。answer CE 仍保留，但与 queried final-state CE 指向同一组 logits；不增加参数，不使用 teacher answer、hard state、argmax 或答案旁路。

## 3. Gate 与归因

先运行 overfit32；通过后使用 data seed `20260721/22/23`、model seed `20261521/22/23` 三组 fresh formal。Gate 与 A1.13 相同；ordinary formal 通过的 run 再运行结构反事实、same-answer、disable recurrence 与错误 start-state permutation。

- A1.13 STRUCTURED-CLOSURE state `3/3`、完整非 `3/3` 且失败均为 answer-only，A1.15 完整 formal/intervention `3/3`：根因闭合为三个相互独立的缺失合同——generic transition 缺少关系寻址 identity、连续 latent 缺少 closure、独立 pooled answer 与 state 脱钩。
- A1.15 仍失败：query binding 或联合 state 的 heldout 稳定性仍未闭合，不能声称根因确认。

即使 A1.15 通过，证据仍只覆盖 exact-symbolic 三寄存器核心，不覆盖 learned full-text Boundary、Qwen、匿名开放世界 workspace、matched text-CoT、V2-A3/V2-A4 或 V2-B。

## 4. 正式结果

触发条件成立：A1.13-STRUCTURED-CLOSURE 的 state Gate 为 `3/3`，完整 Gate 为 `1/3`，另外两个 run 均为 answer-only failure。A1.15 的 length-balanced overfit32 在 step `1000` 首次全通过，并在 step `1200` 确认。

fresh model seed `20261521/22/23` 的正式结果均为 state/full `failed`，合计 state `0/3`、full `0/3`。三个 run 的 answer-state prediction consistency 均为 `1.0`，说明接线约束确实消除了答案与预测 state 的数值脱钩；但模型本身没有进入 state 学习相变，因此没有 run 触发因果干预。机器判定为 `closed_coupled_core_insufficient`。

该结果否定“只需把答案接到最终 state 即可闭合当前 core”。由于 A1.15 同时删除独立 pooled-answer objective，并在同一 queried-state logits 上保留重复 answer CE，它尚不能区分 readout topology 与训练目标的影响；此区分由 A1.16 和 A1.17 完成。
