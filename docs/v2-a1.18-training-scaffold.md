## 1. 问题与目标

A1.17 已证明，relation-addressed transition + soft prototype closure 的 state 学习依赖独立 `workspace mean → answer` objective 提供的全局梯度；一旦把正式答案强制接到 queried state，无论保留或删除重复 answer CE，state 都是 `0/3`。这个结果暴露的不是单纯读出错误，而是训练目标悖论：核心需要一个不能作为正式因果答案接口的路径才能进入可学习盆地。

A1.18 不再继续归因 loss 权重、学习率、宽度或层数，而是建立长期训练合同：正式答案始终由最后一步 queried entity 的共享 state head 产生；训练期可以增加状态语义对齐的全局辅助监督；formal 前必须物理删除辅助头。目标是找到不依赖 queried-answer 标签、又能稳定提供递归信用分配的训练机制。

## 2. 固定合同

目标 core 仍是 A1.13 的 exact-symbolic relation-addressed transition + soft prototype closure。训练损失固定为：

```text
L = per-step state CE + prototype closure cosine + global state auxiliary CE
```

正式 query-coupled answer CE 权重固定为 `0`。checkpoint 只按 trajectory、final state 和 state token 指标选择，不读取辅助准确率。formal run 固定训练 `4000` 步，不使用 patience early-stop。

训练结束后导出 `deployable.pt`：删除全部 `training_auxiliary_head.*` 参数，把模型配置中的辅助类型改为 `none`，再用 strict state-dict load 验证。formal loader 会拒绝训练checkpoint、仍声明辅助类型的checkpoint或仍包含辅助参数的checkpoint。formal 与 intervention 只读取该部署artifact。

## 3. 三种训练辅助

`QAUX` 复用 A1.13 独立 pooled-answer head 的逐位相同初始化，从最终 workspace mean 预测 queried answer。它只作为答案标签阳性控制。

`FINAL-SAux` 从最终 workspace mean 同时预测三个寄存器的完整终态。它移除了 query-specific answer 标签，但仍只在递归末端提供一次全局状态梯度。

`TSAUX` 使用一组跨步共享的线性头，在每一个递归步从 `mean(LayerNorm(workspace_t))` 预测该步三个寄存器的完整状态。它不增加推理模块，不接收 queried-answer 标签，也不使用每步独立参数；作用是让每一步全局 workspace 都对完整状态可辨识。

## 7. 结论

机器分类为 `per_step_global_state_credit_assignment_confirmed`，`mechanism_solved=true`。当前训练目标悖论的直接机制是：逐槽 per-step CE 与 latent closure 仍缺少从每一步全局 workspace 到完整状态的密集信用分配；final-only 全局状态梯度能工作但 seed 不稳定；每步共享的全局完整状态辅助把该信号变成稳定训练机制。

因此在本诊断 core 内，不需要 answer-specific auxiliary，也不需要保留推理答案旁路。A1.18B 将以下内容确立为后续架构的训练协议，而不是临时修复：

1. 正式答案始终从 query-coupled state 产生；
2. 训练期每一步都施加全局完整状态辅助；
3. 正式 answer CE 不重复反传；
4. checkpoint 选择只看 state；
5. 部署前物理删除辅助头；
6. formal 后必须通过 causal intervention。

这只把 exact-symbolic 三寄存器 core 的机制层从失败改为通过，不等于完整 V2-A 通过。A1.18/A1.18B 九个正式run的累计训练进程时间为 `15194.85` 秒；该数字不含 overfit、formal evaluation 和 intervention，也不是与 text-CoT 的成本对照。

## 8. 未解决边界与下一阶段
