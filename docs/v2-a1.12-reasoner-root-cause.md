# V2-A1.12：Reasoner 根因 2×2 定位

日期：2026-07-16

状态：已完成；三条新臂均为 formal `0/3`

## 1. 要回答的问题

A1.11 已确认 exact-symbolic typed roles → anonymous `K=8` generic recurrent reasoner 在 overfit32 可拟合、formal 稳定 `0/3`，所以 A1.10 不是纯 Boundary × Reasoner 组合故障。但 A1.11 Reasoner 同时缺少稳定 entity address 与 operation-step cursor，仍不能判断失败来自哪一项，或二者是否必须共同存在。

A1.12 只测试这两个变量。Qwen、Boundary adapter、structured A1.8 core、COPY/SWAP 专用 transition、prototype closure、teacher state、宽度、层数、训练长度、损失和 Gate 均冻结。

| anonymous `K=8` | A1.11-Reasoner：formal `0/3` | A1.12-CURSOR |

## 3. 冻结的共同合同

输入直接由不可变 A1.8 records 构造，不加载 Qwen、token cache、role adapter 或 structured core：10 类 value、2 类 operation family、3 类 register identity 使用固定 one-hot；start-register 0/1/2、query、family、source、target 使用 role-type one-hot；operation position 使用固定 sinusoidal features。operation mask 只用于构造 exact typed sequence、cursor 与 persistence，不进入任何任务专用 transition。

三臂均使用 `K=8`、`D=256`、8 heads、FFN 1024、两层跨 step 共享的 pre-norm self-attention/cross-attention/Dense FFN。训练 T1–16，统一运行 16 recurrent steps；程序结束后监督 final-state persistence。state CE 和 answer CE 权重均为 `1.0`，batch `32`，学习率 `3e-4`，最多 4000 steps，每 200 steps validation，patience 6。禁止增加宽度、层数、训练步、辅助 loss、teacher forcing、hard re-embedding 或答案旁路。

## 4. 两个实验变量

### 4.1 Entity-addressable state

anonymous 条件保持 A1.11：八个 learned queries，trajectory state logits 来自 permutation-invariant workspace mean → 30-way state head。

entity-addressable 条件只改变状态契约：前 3 个 slot 固定对应 amber/cobalt/jade，以 exact start value one-hot + register identity one-hot 的共享 projection 初始化；后 5 个仍是通用 scratch slots。trajectory state logits 由同一个共享 10-way head分别读取前三个 slot。通用 recurrent blocks、source projection 和独立 pooled answer head不变；不加入 register-specific transition、COPY/SWAP branch 或显式 source→target 写入。

因此 BIND 通过只能说明“稳定 entity address + addressable state readout”这一最小状态契约足以修复，不能把收益进一步拆成 initialization 与 readout 两项。

### 4.2 Operation-step alignment

full-program 条件保持 A1.11：初始读取和每个 recurrent step 都可 cross-attend 完整 typed source，模型必须自行学习内部时钟与 operation 选择。

cursor 条件只改变 source 可见性：初始读取仅看 3 个 start tokens 与 query token；第 `t` 个 recurrent step 只看 query token和第 `t` 个 family/source/target tokens。超过真实 program length 后 operation tokens 被 mask，只保留 query token以监督状态保持。cursor 不执行操作，也不含 family-specific 参数；状态更新仍完全由相同 generic recurrent blocks 学习。

## 6. 归因规则

只按三 seed formal 主结果归因，intervention 只增强证据：

- BIND `3/3`、CURSOR `0/3`：缺少 entity-addressable state 是主根因；cursor 不是必要修复；
- BIND `0/3`、CURSOR `3/3`：缺少 operation-step alignment 是主根因；显式 entity address 不是必要修复；
- BIND `3/3`、CURSOR `3/3`：两者都是独立充分的替代修复，不能声称唯一根因；A1.11 失败来自共同缺少约束；
- BIND `0/3`、CURSOR `0/3`、BOTH `3/3`：binding 与 cursor 存在必要交互，二者共同缺失是根因；
- BOTH `0/3`：这两个候选不足，根因继续落在 generic transition、continuous state closure 或目标函数；不得把部分指标提升写成定位成功；
- 任一关键臂为 `1/3` 或 `2/3`：seed 不稳定，不能作唯一归因。

如果 BOTH 仍失败，下一阶段只能单独测试 prototype closure／transition identity；不得在本轮临时加入第三变量救援。

## 7. Formal 后干预

任何 formal 通过臂必须在 exact-symbolic causal records 上测试 prefix、replacement、deletion、operation shuffle、query swap、same-answer/different-trajectory、disable recurrence 与输入 start-state permutation。结构反事实对新 trajectory/answer 的跟随率不低于 `0.95`；发生变化的旧 trajectory 保留率不高于 `0.05`；disable recurrence 和错误 start-state permutation 的 trajectory 不高于 `0.20`。

本轮不包含 full-text Boundary、matched text-CoT Pareto、A3/A4 或 V2-B。

## 8. 正式结果

三条新臂的 length-balanced overfit32 均通过，证明每种配置都有小样本记忆容量。随后九个 fresh formal 全部按预注册合同执行：BIND、CURSOR、BOTH 均为 `0/3`，没有任何 run 获准运行 intervention。
