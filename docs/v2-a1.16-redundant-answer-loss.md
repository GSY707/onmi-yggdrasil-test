# V2-A1.16：Query-coupled readout 的冗余答案损失检验

日期：2026-07-17

状态：已完成；触发条件成立，但 formal state/full Gate 均为 `0/3`，阶段失败

## 1. 问题

A1.15 删除独立 pooled answer head，令 answer logits 精确等于最后 recurrent step 中 query register 对应 entity slot 的共享 state-head logits。但训练仍保留权重 `1.0` 的 answer CE。此时 answer target 与 queried final-state target 完全相同，answer CE 不再提供新监督，而是把一个终态寄存器相对全部 `16 × 3` 个逐步状态位置重复加权。

若 A1.15 的状态学习比 A1.13-STRUCTURED-CLOSURE 更不稳定，候选原因不是 readout coupling 本身，而是这项重复目标改变了 transition/closure 的优化盆地。

## 2. 唯一变量

A1.16 完整复用 A1.15 的模型前向：exact symbolic entity/cursor、relation-addressed shared transition、soft prototype closure、query-coupled answer、相同 K/D、数据、batch、学习率、训练步数、checkpoint scoring 与 formal Gate。

唯一变化是把冗余 answer CE 从总损失中删除：

`loss = state_ce + closure_loss`

answer logits、answer metric 与全部 answer Gate 继续保留。由于 answer logits 与 queried final-state logits 为同一个 tensor，只要 final state 正确，answer 必须同步正确；不得增加新的答案头、detach、teacher answer、hard state 或后处理。

## 3. Seed 与停止规则

先运行 length-balanced overfit32，T1–16 trajectory/final/answer 必须全部 `1.0`。通过后运行 fresh formal：data seed `20260721/22/23`，model seed `20261621/22/23`。formal state/answer Gate 与 A1.15 完全一致；ordinary formal 通过后才运行相同因果干预。

- A1.15 state 非 `3/3`、A1.16 full formal/intervention `3/3`：根因进一步定位为 query coupling 后保留冗余 answer CE 所产生的目标冲突；readout coupling 本身成立。
- A1.16 仍非 `3/3`：当前 relation transition＋closure 的 seed 稳定性仍不足，不能继续用小幅 loss 权重或学习率 sweep 救援。

即使通过，证据仍只覆盖 exact-symbolic 三寄存器核心，不覆盖 learned full-text Boundary、匿名开放世界 workspace、Qwen、matched text-CoT、A3/A4 或 V2-B。

## 4. 正式结果

A1.15 overfit32 通过且 formal state 为 `0/3`，所以触发条件成立。A1.16 的 no-answer-CE overfit32 在 step `600` 首次全通过，并在 step `800` 确认，说明前向合同和损失仍具备小样本可拟合性。

fresh model seed `20261621/22/23` 的正式 state/full 均为 `0/3`。三个 run 的 short trajectory/full-state 约为 `0.01/0.06–0.07`，relation T16 与 supported OOD T24 trajectory 均为 `0`；answer-state prediction consistency 仍为 `1.0`。ordinary formal 均失败，因此按停止规则没有运行干预。机器判定为 `redundant_answer_ce_removal_insufficient`。

结果否定“删除重复 answer CE 本身即可恢复稳定学习”。但 A1.13 与 A1.15/A1.16 使用了不同 model seed，仍存在 objective 与初始化混杂；唯一有判别力的下一步是 A1.17 在 A1.13 成功 seed 上重跑 coupled-CE 与 coupled-noCE，而不是继续调整 loss 权重或学习率。
