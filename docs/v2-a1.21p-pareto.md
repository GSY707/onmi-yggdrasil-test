# V2-A1.21P matched Pareto 实验记录

日期：2026-07-18

结论：候选机制成立，正式 A1.21P 不通过；按阶段停机规则不运行 A1.22A。

## 判定原则

A1.21P 不是“latent 在几个样本上比 base model 快且准”就通过。它必须同时回答三个问题：

1. 质量是否在充分规模的 heldout 与因果矩阵中稳定；
2. 成本比较是否包含在线 Qwen 编码、训练、teacher data、FLOPs、activation/KV，并对基线公平；
3. 能力是否越过同一 COPY/SWAP 代数的表面改写，在新的可执行 relation/algebra/planning family 上仍成立。

本轮第一个问题形成了强诊断正证据，后两个问题没有闭合，因此不能把 candidate 升级为 matched Pareto。

## 已完成的实验

### K=1 容量负基线

单 slot recurrent baseline 在 overfit32 继续训练后可以拟合小样本，但 2048 条 validation 的 trajectory/final-state/state-token/answer 只有 `0.106934/0.333008/0.497406/0.550293`。这支持多实体可寻址 workspace 的容量价值；它不是与当前 hybrid 等预算的完整替代模型。

### 在线 Pareto smoke

三个路径使用同一个在线加载的 frozen Qwen3.5-2B；hybrid latency 包含 Qwen encode，没有以 cached hidden 冒充在线成本。prompt 已切换为官方 chat template，并关闭 thinking。每个表面族只抽取五条，结果如下：

| family | path | answer | trajectory | median latency |
| --- | --- | ---: | ---: | ---: |
| canonical | direct | 0.00 | 0.00 | 0.586 s |
| canonical | text-CoT | 0.40 | 0.00 | 45.235 s |
| canonical | hybrid | 1.00 | 1.00 | 0.489 s |
| routing surface | direct | 0.00 | 0.00 | 1.540 s |
| routing surface | text-CoT | 0.00 | 0.00 | 47.438 s |
| routing surface | hybrid | 1.00 | 1.00 | 1.567 s |

这足以保留 hybrid candidate，但样本数太小。routing text-CoT 还复用了 canonical demonstrations，direct/text-CoT 只做 deterministic prompting，而 hybrid 已接受大量监督训练，所以该表不能作为公平 Pareto 的正式估计。

### 稳定性与因果

canonical 完整 split matrix、hidden causal audit 和三个 routing continuation schedule 均通过放宽机制门。三条 continuation checkpoint 的 family-head 权重不同，但共享初始 reader/core/data；它们证明对 batch 顺序不敏感，不是三个 fresh model/data seeds。

## 正式 Gate

机器判定 `artifacts/v2-a/a1_21p/assessment-summary.json` 的六项机制门全部通过，但以下六项正式门失败或缺失：

| 正式缺口 | 判定 |
| --- | --- |
| strict joint validation eligibility `3/3` | `0/3`；三个 run 的细粒度最差 cell 未过 A1.20C eligibility |
| 每个 family 至少 64 条在线样本 | `5/5`，不足 |
| 第二个可执行 algebra/planning family | 缺失；routing 明确是 `surface_only_transform=true` |
| 三个 fresh model + data seeds | 缺失；只改变 continuation schedule |
| matched training 与 teacher-data budget | 无审计 artifact |
| FLOPs、activation/KV、teacher 全成本 | 无审计 artifact |

机器分类为 `full_text_hybrid_candidate_confirmed_but_matched_pareto_not_closed`，并写入 `a121p_passed=false`、`a122a_authorized=false`。

## 为什么现在停止

继续把五条扩成几十条只能修补样本规模，不能修复任务族和公平预算。直接进入 A1.22A 又会把 natural-language audit 建在一个尚未证明 Pareto 的候选上，违反用户要求的阶段硬顺序。

下一轮应重新定义 A1.21P，而不是继续在 routing 表面域上微调：

- 设计真正改变可执行代数的任务族，例如带条件分支、可逆/不可逆关系合成或资源约束规划；不能只重命名 COPY/SWAP；
- 给 text-CoT 建立同 family demonstrations，并预注册相同 teacher/训练资源口径；
- 从三个独立 data、reader、core seed 训练，而不是从同一 joint checkpoint 继续；
- 至少每 family 64 条在线 matched evaluation，并把 Qwen encode、生成、latent recurrence、训练、teacher 生成和审查成本放进同一账本；
- 先恢复细粒度 joint eligibility `3/3`，再运行正式 Pareto。

只有上述正式门全部通过，A1.22A 才能解锁。当前 V2-A/R1 仍未关闭，V2-B 仍不启动。
